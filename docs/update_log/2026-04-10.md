## Live LiDAR-HMR in ViT (in-graph)

### Added / changed

- `pretrain/mmpretrain/models/utils/lidar_hmr_meshgraphormer.py` — **LiDARHMRPoseMeshGraphormerEncoder**: builds upstream `pose_meshgraphormer` under `lidar_hmr_root`, runs real forward, pools `vert_feat` to `(B, T, 48)`.
- `pretrain/mmpretrain/models/backbones/vision_transformer_with_depth.py` — `use_lidar_hmr_depth`, `lidar_hmr_encoder` config; `forward(..., point_clouds=)` runs encoder before disk `depth_embed_path`.
- `pretrain/mmpretrain/models/classifiers/image.py` — stacks `human_points_local` from each `DataSample` into `point_clouds`; **filters backbone kwargs** so plain `VisionTransformer` works again when depth kwargs are absent.
- `pretrain/configs/_base_/models/vit-base-p16_lidar_hmr_depth.py` — example backbone + encoder flags for training.

### Data

- Pack points with `PackInputs(..., algorithm_keys=('human_points_local',))`; tensor shape `(N, 3)` per sample. Encoder resamples to `num_points` (default 1024) along N.

### Runnable pretrain command (LiDAR-HMR + ViT, not BEDLAM2 pose)

- Config: `pretrain/configs/lidar_hmr_vit/vit_b16_lidar_hmr_cifar10.py` — CIFAR-10 + `RandomHumanPointsPlaceholder` (swap for real points).
- Transform: `mmpretrain.datasets.transforms.RandomHumanPointsPlaceholder` sets `human_points_local` for debugging.
- Run from `pretrain/`; see the config header for `dist_train.sh` + `PYTHONPATH` (pointops + LiDAR-HMR).

### BEDLAM2 + LiDAR-HMR (pose path, not pretrain classifier)

- **Removed** the parallel pretrain-only setup: `pretrain/configs/lidar_hmr_vit/vit_b16_lidar_hmr_bedlam2.py` and `pretrain/mmpretrain/datasets/bedlam2_lidar_vit.py`. LiDAR-HMR is only a **geometry encoder** fused into the **same** BEDLAM2 3D pose stack.
- Config: `pose/configs/sapiens_pose/bedlam2/sapiens_0.3b-50e_bedlam2-640x384.py` — set **`use_lidar_hmr_fusion = True`** for depth → point cloud (`BedlamDepthToPointCloud`) → `LiDARHMRPoseMeshGraphormerEncoder` tokens fused in **`SapiensBackboneRGBLidarFuse`** with RGB ViT features; **`RGBDPose3dEstimator`** passes `human_points_local` from `PackBedlamInputs`. Default **`False`** keeps legacy **`SapiensBackboneRGBD`** (4-channel patch embed).
- `PYTHONPATH`: `pose`, `pretrain`, `engine`, plus LiDAR-HMR `third_party/` and `PointTransformerV2/libs/pointops` as in the config header when fusion is on.

### LiDAR-HMR pretrained checkpoint loading

- `pretrain/mmpretrain/models/utils/lidar_hmr_meshgraphormer.py` — `load_pose_meshgraphormer_weights()` plus `LiDARHMRPoseMeshGraphormerEncoder(lidar_hmr_pretrained=...)`. Accepts upstream ``{'net': ...}`` checkpoints, strips ``module.`` / ``pmg.`` prefixes for full ``LiDAR_HMR`` saves, shape-filters, ``strict=False``.
- `pose/configs/sapiens_pose/bedlam2/sapiens_0.3b-50e_bedlam2-640x384.py` — when fusion is on, default `lidar_hmr_pretrained` is `lidarh26m/lidar_hmr_mesh.pth` after unzipping `lidarh26m.zip` at repo root; override with `LIDAR_HMR_PRETRAINED` or `none` / `false` / `0` to skip loading.
- `pretrain/.../vision_transformer_with_depth.py` — nested `MODELS.build` for the LiDAR encoder now sets `_scope_='mmpretrain'` so MMEngine does not resolve the child module under the Runner’s `mmpose` scope.
- BEDLAM2 fusion `mesh_config` default: `configs/mesh/lidarh26m.yaml` (matches `lidar_hmr_mesh.pth`; differs from `sloper4d.yaml` only in `PCD_LAST`).
- `pose/tools/verify_lidar_fusion_smoke.py` — optional forward/backward smoke (needs LiDAR-HMR Python deps).

### Disable LiDAR-HMR

- In backbone config: `use_lidar_hmr_depth=False`, omit or set `lidar_hmr_encoder=None`; optional `depth_embed_path` for `.npy` tokens only.

### ``USE_LIDAR_HMR_FUSION`` (env)

- ``pose/configs/sapiens_pose/bedlam2/sapiens_0.3b-50e_bedlam2-640x384.py`` — ``use_lidar_hmr_fusion`` is set from ``USE_LIDAR_HMR_FUSION`` (``1``/``true``/``yes``/``on``) so training can enable LiDAR-HMR + ViT fusion without editing the file.

### BEDLAM2 ``BEDLAM2_DATA_ROOT`` (layout on disk)

- Set to the **parent of** ``data/`` (e.g. ``/media/s/Crucial X10/BEDLAM2`` when labels are under ``.../BEDLAM2/data/label/...``). Do **not** set ``.../BEDLAM2/data`` — :class:`~mmpose.datasets.datasets.body3d.bedlam2_dataset.Bedlam2Dataset` joins ``{data_root}/data/{label,depth,frames}``.

### Rome tracking subset (`splits_rome_tracking.json`)

- `pose/data/bedlam2_splits/rome_tracking_train_seqs.txt` (90) + `rome_tracking_val_seqs.txt` (10) derived from the JSON `train` list (100 sequences). `rome_tracking_all100_seqs.txt` lists all 100 for train-only + `--no-validate` if desired.
- `pose/scripts/finetune/bedlam2/sapiens_0.3b/node.sh` — comment block with example `--cfg-options` overrides.
