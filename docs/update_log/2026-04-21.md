## Panoptic Kinect1 preprocessing (Part A)

Added offline preprocessing utilities for CMU Panoptic Kinect v2 data: decode `depthdata.dat` (same layout as CMU `readDepthIndex_1basedIdx.m`), unproject/project using `kcalibration` (ports of toolbox MATLAB), HD↔Kinect sync via `ksynctables`/`synctables`, splat aligned depth onto RGB resolution, optional RGB undistort + overlay QA images.

### Files

- `pose/tools/__init__.py` — package marker so `tools.panoptic` imports work when `pose/` is on `PYTHONPATH`.
- `pose/tools/panoptic/__init__.py` — same.
- `pose/tools/panoptic/depth_io.py` — read raw depth frames from `depthdata.dat`.
- `pose/tools/panoptic/kinect_project.py` — `unprojectDepth_release` / `PoseProject2D` logic + z-buffer splat to RGB grid.
- `pose/tools/panoptic/sync_tables.py` — load sync JSON and pick 1-based color/depth indices for an HD time.
- `pose/tools/panoptic/preprocess_panoptic_kinect1.py` — CLI driver; writes per-frame `*_meta.json`, `manifest.json`, NPY/JPG outputs.

### Usage

From repo root (with OpenCV + NumPy):

```bash
python pose/tools/panoptic/preprocess_panoptic_kinect1.py \
  --sequence-dir /path/to/SEQ \
  --output-dir /path/to/out \
  --kinect-node 1 \
  --hd-output-frames 500 \
  --max-frames 1
```

Requires sequence layout: `kcalibration_*.json`, `ksynctables_*.json`, `synctables_*.json`, `kinectVideos/kinect_50_XX.mp4`, `kinect_shared_depth/KINECTNODEX/depthdata.dat`.
